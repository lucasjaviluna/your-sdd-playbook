# Bienvenido al SDD Playbook

## ¿Qué es este repositorio?

Este repositorio es una guía práctica para aprender y aplicar **Specification-Driven Development (SDD)** utilizando herramientas modernas de desarrollo asistido por Inteligencia Artificial.

No es únicamente un curso ni una colección de documentos. Es un manual de trabajo que muestra cómo transformar una idea de negocio en software funcional siguiendo un proceso ordenado, repetible y trazable.

A lo largo de este playbook aprenderás a trabajar con:

* Azure DevOps para la gestión del backlog.
* OpenSpec para la gestión de especificaciones.
* GitHub como repositorio del proyecto.
* Claude Code para implementar funcionalidades guiadas por especificaciones.
* GitHub Copilot como asistente durante el desarrollo.
* GitHub Pull Requests para revisar tanto el código como las especificaciones.

El objetivo no es aprender una herramienta aislada, sino comprender cómo integrarlas dentro de un flujo de trabajo coherente.

---

# ¿A quién está dirigido?

Este material está pensado para:

* Desarrolladores Frontend.
* Desarrolladores Backend.
* Arquitectos de Software.
* Tech Leads.
* AI Champions.
* Equipos que desean incorporar IA a su proceso de desarrollo sin perder control ni calidad.

No es necesario tener experiencia previa con OpenSpec, aunque sí se recomienda conocer Git y trabajar habitualmente con un sistema de gestión de tareas como Azure DevOps o Jira.

---

# ¿Qué aprenderás?

Durante este recorrido aprenderás a:

* Convertir una User Story en una Specification completa.
* Diseñar soluciones antes de escribir código.
* Utilizar la Specification como fuente de verdad.
* Guiar agentes de IA mediante contexto estructurado.
* Mantener la documentación sincronizada con el código.
* Definir pruebas a partir de la especificación.
* Integrar Specification-Driven Development en un entorno empresarial.

---

# Filosofía del repositorio

Todo el contenido sigue una idea central:

> **El código implementa una Specification; no la reemplaza.**

En SDD, el código es una consecuencia de un buen diseño y una buena especificación.

Por ese motivo, este repositorio dedica tanto esfuerzo a documentar el problema como a implementar la solución.

Puedes recorrer el contenido de dos maneras:

2. Módulo 1 – Fundamentos.
3. Módulo 2 – OpenSpec.

## Consulta rápida

Si ya conoces SDD, utiliza este repositorio como material de referencia para consultar:

* estructuras de Specifications;
* plantillas;
* buenas prácticas;
* ejemplos de prompts;
* flujo de trabajo recomendado.

---

# Proyecto de referencia

Todo el curso se desarrolla sobre un mismo caso práctico: **Customer Portal**.

En lugar de utilizar ejemplos aislados, construiremos una aplicación ficticia con funcionalidades típicas de un entorno empresarial, como autenticación, actualización de datos, consulta de beneficios y gestión de medios de pago.

Cada Specification, diseño, tarea y ejemplo de código pertenecerá a este mismo proyecto, permitiendo seguir el ciclo completo de desarrollo.

---

# Objetivo final

Al finalizar este playbook serás capaz de tomar una User Story de Azure DevOps, convertirla en una Specification utilizando OpenSpec, implementarla con ayuda de Claude Code y GitHub Copilot, validarla mediante pruebas y entregarla mediante un Pull Request con trazabilidad completa.

Ese es el verdadero propósito de Specification-Driven Development: convertir el desarrollo de software en un proceso más claro, predecible y preparado para trabajar con Inteligencia Artificial.
